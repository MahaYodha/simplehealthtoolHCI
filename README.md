# Mental Health Challenges Rating Tool

This tool helps teams rate and prioritize mental health challenges. It provides a collaborative way to assess various challenges and visualize the results.

## How to Use

1. Open the `index.html` file in your web browser
2. Each team member can rate the challenges using the dropdown menus
3. Ratings are:
   - High (3 points)
   - Medium (2 points)
   - Low (1 point)
4. Once all ratings are complete, the tool will show:
   - A bar chart of the top challenges
   - A detailed list of challenges with scores
5. You can:
   - Change how many top challenges to display (3, 4, or 5)
   - Export the data to CSV
   - Generate sample data to see how it works

## Sharing Results

1. After completing the ratings, click "Export to CSV" to save the data
2. Share the CSV file with the team for further analysis
3. The CSV includes:
   - All challenges
   - Individual ratings
   - Average scores

## Technical Details

- Works in any modern web browser
- No installation required
- All data is processed locally (no server needed)
- Uses React, Chart.js, and Tailwind CSS
